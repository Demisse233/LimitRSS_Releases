# LimitRSS Downloads / 安装包

Official LimitRSS installers. [Latest release / 最新版本](https://github.com/Demisse233/LimitRSS_Releases/releases/latest)

Source code is maintained separately. This repository contains installers, checksums and release notes only.

- Android: Debug signing certificate, not a store distribution key.
- iOS: unsigned IPA including Widget; re-sign before installation.
- macOS: Apple Silicon / Intel, ad-hoc signed, not notarized.
- Windows: x64 / ARM64, unsigned installers and portable ZIPs.
